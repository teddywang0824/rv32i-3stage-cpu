正式 RTL 目標 · RV32I CPU Core v1.0

完成四級、single-issue、in-order 的 RV32I Core：支援 40 條 RV32I base instruction，具同步 Instruction/Data Memory transaction contract、precise trap interface 與 retire trace；通過 directed、整合、程式映像與 architectural tests 後封存 RTL。此目標不包含 CSR／privileged mode、interrupt、RV32M、cache、MMU、實體記憶體 macro 與後段實作。

必須完成完成定義明確排除
現有 37 條指令，加上 FENCE、ECALL、EBREAK 合法指令結果正確；illegal、breakpoint、environment call 與 alignment fault 產生明確且精確的 trap，不再靜默忽略 Zicsr、machine-mode CSR、interrupt、RV32M 與 SoC 周邊另立里程碑

目標架構

同步 Instruction Memory 的 response register 形成取指與解碼邊界；同步 Data Memory 則將位址計算與記憶體回應／寫回分成兩級。

IF · 取指PC → 同步 Program ROM
response valid、PC 與 instruction 成組保存
→
ID · 解碼拆解指令、讀 Register File、產生 immediate 與控制訊號
→
EX · 執行ALU effective address、branch/jump 決策，以及送出 Data Memory request
→
MEM / WB接收同步 read data、Load 對齊與擴展，以及統一回寫 rd
